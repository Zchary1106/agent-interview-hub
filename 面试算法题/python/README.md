# 2026-10 算法题 Python 参考实现

[题干、参考答案与来源](../2026-10-算法与手写面试题与参考答案.md) · [实现](algorithm_answers.py) · [测试](test_algorithm_answers.py)

Python 3.11+，实现仅依赖标准库，测试使用 pytest。共 15 道题，岛屿题提供 DFS/BFS 两种实现。代码为面试练习，不是生产库。

## 输入契约

- 深合并：无环 JSON 兼容字典；同名字典递归合并、列表拼接、其他类型右侧覆盖；不修改或共享可变输入。
- LRU：非负整数容量（0 表示不缓存）；哈希索引 + 手写双向链表，均摊 O(1)，非线程安全。
- 增量 JSON：UTF-8 字节流、顶层仅对象/数组；不接受顶层标量。支持跨块 UTF-8、字符串转义和相邻对象，设有单条缓冲大小限制；不是通用 SAX/生产解析器。
- IP：遵从 Python 标准库的严格 IPv4/IPv6 地址校验，拒绝不规范形式。
- 链表、树：无环结构；删除倒数节点时 N 必须在有效范围内。
- 股票：最多 K 次、不同时持仓多份；不含手续费和冷却期。
- 区间：半开 `[start, end)`；先归一化，空区间不贡献长度。
- LIS：严格递增；岛屿：矩形 0/1 网格、上下左右连通，空输入有效。
- 其余函数的完整边界、参数和复杂度见各自 docstring 与测试。

## 运行

从仓库根目录运行：

```bash
python3 -m pip install 'pytest>=8,<10'
python3 -m pytest -q 面试算法题/python/test_algorithm_answers.py
```

40 项离线测试包含固定边界、固定种子的随机/穷举独立 oracle、UTF-8 逐字节分块、深层 JSON 和超大整数等。通过仅证明测试覆盖的输入契约，不代表任意输入、并发、恶意资源消耗或线上流量下都可靠。
