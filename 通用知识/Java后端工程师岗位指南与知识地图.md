# Java 后端工程师岗位指南与知识地图

> 首批正式内容：面向 Java 后端方向的岗位要求、能力要求 → 知识地图与面试准备路线，覆盖语言基础、数据库与缓存、分布式与系统设计、项目表达四个阶段。

---

## 一、岗位画像

**典型 JD 关键词**：Java、Spring Boot、MySQL、Redis、消息队列（Kafka/RocketMQ）、微服务、分布式、性能优化、高并发、Docker/K8s。

| 维度 | 常见要求 |
|------|---------|
| 语言与工程 | Java 8+、集合与并发、JVM 调优、Maven/Gradle、Git |
| 框架 | Spring Boot / Spring Cloud、MyBatis / JPA |
| 数据层 | MySQL 索引与事务、Redis 缓存、消息队列、分库分表 |
| 分布式 | 微服务拆分、服务治理、分布式事务、幂等、限流熔断 |
| 系统设计 | 高并发读写的通用架构、缓存/异步/削峰、可观测性 |
| 项目表达 | 项目背景、架构决策、性能指标、故障复盘 |

| 能力要求 | 知识阶段 | 对应知识单元 | 掌握标准 |
|---------|---------|-------------|---------|
| 语言与 JVM 基础扎实 | 核心基础 | Java核心基础-语言集合异常JVM并发 | 能讲清集合选型、并发工具与 JVM 内存模型 |

## 三、面试准备路线（建议 4 周）

1. 第 1 周：Java 核心基础（集合、并发、JVM）+ 每日 3 道手写题。
2. 第 2 周：数据库与缓存（索引、事务、Redis）+ 整理缓存一致性笔记。
3. 第 3 周：分布式与系统设计（微服务、消息队列、限流熔断）+ 完成 1 个系统设计演练。
4. 第 4 周：项目表达（指标、故障、取舍）+ 2 场模拟面试 + 错题进复习队列。

## 四、高频面试题（首批）

1. Java 集合框架里 ArrayList 和 LinkedList 的区别，扩容机制是什么？
2. HashMap 在并发下为什么会死循环（JDK 7）？ConcurrentHashMap 如何解决？
3. 线程池的核心参数有哪些？任务提交后如何排队？
4. JVM 内存区域划分，垃圾回收如何判断对象可回收？
5. MySQL 为什么用 B+ 树做索引？什么情况下索引会失效？
6. 事务的隔离级别有哪些？MySQL 默认是什么？幻读如何解决？
7. Redis 缓存与数据库如何保证一致性？缓存穿透/击穿/雪崩怎么处理？
8. 分布式事务有哪些方案？如何保证最终一致性？
9. 消息队列如何保证消息不丢失、不重复消费？
10. 微服务下如何做限流、熔断与降级？
11. 系统设计：如何设计一个秒杀系统？
12. 你项目中遇到的最大故障是什么？如何定位与修复？

> 参考答案见本目录各阶段知识单元的「高频面试题」章节；全部答案也随知识同步进入题库。
